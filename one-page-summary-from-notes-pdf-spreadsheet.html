What a one-page summary is (and is not)

A one-page summary is a single page that tells a busy reader what happened, what it means and what to do next. It is not a shortened copy of the original: a ten-page report cut to one page by deleting sentences still reads like ten pages. The useful version is rebuilt around headlines, with the detail moved into one chart, table or flow.

Five steps to a one-page summary

  1. Name the one decision or question. Write it at the top in a sentence: “Should we extend the pilot?” Everything on the page must help answer it.
  2. Cut to three or four headlines. Each headline is a full claim, not a topic: “Sign-ups doubled after the March change”, not “Sign-ups”.
  3. Pick one visual for the evidence. Use the table in the next section. If the data cannot honestly support a chart, use a short list instead.
  4. End with the next step. Who does what, by when. One line is enough.
  5. Read it in 60 seconds. If you cannot, delete a headline rather than shrinking the font.
